# Credit Intelligence: Zuri AIaaS Intelligence Layer (PI-1)

Real-time credit decisions with reasons: **probability of default → approve / starter loan / decline → top 3 reasons.**

Built for digital-credit partners (Aventus/LendPlus, M-KOPA, Watu) and betting operators on the
Zuri BAaaS platform. Prototype trained on public data (Home Credit, 307K loans); designed to plug
into Doris features + MLRun serving.
